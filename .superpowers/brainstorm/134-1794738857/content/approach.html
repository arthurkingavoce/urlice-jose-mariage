Quelle approche pour le site du mariage ?

Il y a déjà une belle invitation HTML pour Urlice & José. Comment veux-tu construire la suite ?

A

Enrichir l'invitation existante

Ajouter les fonctionnalités (RSVP, livre d'or, liens personnalisés) directement dans le fichier HTML actuel. Une seule page défilante, tout en un.

B

Nouveau site complet

Créer un vrai site web avec plusieurs sections : accueil, programme du 19 décembre, RSVP, galerie photos, livre d'or. L'invitation actuelle devient la section d'accueil.

C

Garder l'invitation + page interactive séparée

L'invitation reste telle quelle (imprimable, envoyable). On crée en plus une page web dédiée aux confirmations de présence et au livre d'or.
